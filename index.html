HTML + JS кодировщик с PIN

Введите исходный HTML/JS код и PIN. Нажмите «Закодировать» — получите готовый самораспаковывающийся HTML-файл.

PIN будет нужен для распаковки сгенерированного файла.
Определяет количество ячеек ввода в защищённой странице.
«Калитка» — один проход XOR-обфускации. Максимальная скорость, минимальная защита. Подходит для лёгкого скрытия от новичков.
Добавьте этот хвост к URL защищённой страницы: protected.html#k=... — по такой ссылке страница откроется без ввода PIN.

Важно: это простая кодировка (варианты XOR). Подходит только для лёгкого скрытия кода и не является криптографической защитой.
